# IMU Data Visualization

The following repository contains a react frontend application that connects to a bluetooth device via browser javascript bluetooth capabilites and outputs 9-dof imu processed and raw data

## Setup
0. Ensure having `npm` correctly installed ([node.js and npm docs](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm))
1. Install react
```
npm install react react-dom
```
2. Install react bootstrap
```
npm react-bootstrap bootstrap
```

## Run
1. Execute the app
```
npm start
```
2. To connect a device in the web-browser go to [Connect a device](http://localhost:3000/connect)
3. Enjoy!
